Detailed Description

template<class View, class Offset>
class Gecode::Int::Circuit::Dom< View, Offset >

"Domain consistent" circuit propagator

Propagates domain consistent distinct, checks that the induced variable value graph is strongly connected, and prunes too shot cycles.
