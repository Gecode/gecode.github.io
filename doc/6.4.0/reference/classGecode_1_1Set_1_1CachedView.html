Detailed Description

template<class View>
class Gecode::Set::CachedView< View >

Cached set view.

A cached set view \(s\) for a set view \(t\) adds operations for caching the current domain of \(t\) and comparing the current domain to the cached domain. Cached views make it easy to implement incremental propagation algorithms.
