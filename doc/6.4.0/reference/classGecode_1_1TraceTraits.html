template<class View>
class Gecode::TraceTraits< View >

Traits for tracing.

The traits used for tracing are as follows:

  • typedef Type TraceView where Type is the type of an appropriate duplicate view of View.
  • typedef Type TraceDelta where Type is the type of an appropriate trace delta for View.
  • typedef Type TraceSlack where Type is the type of an appropriate measure of slack for View.
