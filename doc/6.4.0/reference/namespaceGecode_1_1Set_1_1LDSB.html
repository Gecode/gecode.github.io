ValueSymmetryImp< View > * Gecode::Set::LDSB::specialUpdate ( Space & home,
ValueSymmetryImp< View > * s,
IntSet usedValues )

Bulk update of a value symmetry s, using usedValues.

Calculates the intersection and difference of the values in the symmetry and usedValues, updates the symmetry to eliminate the used values, and makes a new symmetry containing the intersection values, if there are at least two. Returns the new symmetry, or nullptr if the intersection has fewer than two elements.
