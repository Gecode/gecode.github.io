Dear Robe,

while I use MSVC myself for development, I only use it from the commandline,
so my tips are limited: the only thing you need to do to get the stuff up
and running is to make sure that MSVC finds the header files, if you
installed the *.msi package in the default place, it should be something
like
	"c:\Program Files\Gecode\include"

How to the Visual Studio how to use it, check its reference (it should be
found under the header VC++ Directories or something like that if my memory
serves me right).

That should be all

All the best
Christian
