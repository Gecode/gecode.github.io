> The dfs object has a next method that you can call in a loop to get
> more than one solution.  As soon as it returns NULL, the complete
> search tree has been explored:
>
> CSP* c = dfs.next();
> while (c != NULL) {
> 	c->print(); // e.g., output the current solution
> 	delete c;
> 	c = dfs.next();
> }
