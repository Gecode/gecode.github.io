[gecode-users] use of the folder Gecode.lib

Christian SchulteTue Jan 7 15:48:08 CET 2014

You have to recompile your project so that the Gecode version numbers match
(this is as always) on both platforms.



If you want to redistribute your project compiled in debug mode (which you
tried to do but should not) then even the MSVC versions have to match on
both platforms.



Christian
